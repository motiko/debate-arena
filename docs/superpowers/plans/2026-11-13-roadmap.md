# Debate Arena: First-Release Roadmap

Spec: `GLOSSARY.md` and `docs/adr/0001`–`0006`. Each plan produces working, tested software on its own and is written in detail only when the previous one is done, so it can build on real interfaces.

| # | Plan | Delivers | Depends on |
|---|------|----------|------------|
| 1 | **Engine core** ([plan](2026-11-13-engine-core.md)) | pnpm/Turborepo monorepo, oxlint, Vitest, CI; `@debate-arena/engine`: domain types, Classic Format, word limits, model interface + fake, Turn generation, Panel + Self-Judging, Verdict, Oxford Swing, AI Voters, Budget estimate | — |
| 2 | **Platform API on Cloudflare** ([plan](2026-11-13-platform-api.md)) | `apps/api`: Workers API, D1 schema + migrations behind repositories (EU jurisdiction), per-Turn Queue jobs, Durable Object per Debate pushing Turns over WebSocket, OpenRouter `ModelClient` behind the engine interface, Budget reservation + Quota (3/day, Batch counts half), typed `packages/api-client`, `pnpm dev` fully offline with fake models | 1 |
| 3 | **Members and auth** | Better Auth on Workers + D1: Google, GitHub, email magic link, disposable-domain block; Oxford voting endpoints (Members only, Turns gated behind the before-vote, 7-day window); account export and deletion | 2 |
| 4 | **Web Venue** | `apps/web`: Astro + Svelte 5 islands on Workers: feed, Debate page, start-a-Debate flow, voting, live Turn stream, Self-Judging badge, AI-generated labels, i18n-ready strings; Lighthouse CI (Performance ≥ 90, SEO 100, Accessibility 100, mobile + slow 4G) and Playwright + axe as merge gates | 2, 3 |
| 5 | **Moderation** | Motion screen → Flag (never blocks) → Unlisted; Reports with auto-Unlist at 5; Moderator queue and Block | 2, 4 |
| 6 | **AI Voters and Batch Debates** | Opt-in real-time AI Audience (10 platform-chosen AI Voters) on ordinary Debates; Batch Debates via OpenRouter batch: batch-capable models only, half Quota, published when complete, labeled, no Audience Votes or Premiere | 2, 4 |
| 7 | **Delivery and compliance** | GitHub Actions: Turborepo remote cache, per-PR isolated previews (own Workers, D1, DOs, Queues; seeded; fake models unless labeled; deleted on close), production deploy on merge to main; Impressum, privacy policy, cookieless analytics | 2, 4 |

Later, outside the first release: Premieres, CLI Venue, other Venues and identity linking, human Debaters, Personas, Member-made Formats, multi-Judge Panels, translated UIs.
