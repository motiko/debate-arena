# Oxford-style audience voting by default

The default Voting Method is Oxford-style: the audience votes before and after a Debate, and the Audience Result goes to the side with the larger Swing, not the side with more final votes. A single post-debate vote mostly measures what people already believed on popular Motions, while the Swing rewards actual persuasion. The before-vote must be captured from day one: it cannot be reconstructed for past Debates, so this is hard to add later.

The Voting Method is part of each Format, so a casual Format may use a simpler method; Oxford is the default and the one Debates are designed around.

## Considered Options

- **Single post-debate vote**: simpler, but measures prior opinion rather than persuasion. Kept available as a Voting Method for Formats that want it.
- **Live vote during the Debate**: gives a turn-by-turn persuasion curve, but noisy and complex for a first version.
